# What VorT2x stands for

VorT2x exists so that people can run a free operating system on their Apple T2
hardware, and it welcomes everyone regardless of gender identity, sexuality,
origin or background.

Discrimination against people for who they are runs against the reason this
project exists.

This is a statement of the project's values. The code stays free under its
licenses, see [LICENSING.md](LICENSING.md).
